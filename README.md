# Bun Bunli Starter\n\nA Bun starter project with Bunli CLI framework for checking system files.\n\n## Features\n\n- ✨ Built with **Bun** runtime\n- 🎨 **Bunli** CLI framework for command-line tools\n- 📂 System file checker\n- 📁 Directory structure explorer\n- 🎯 TypeScript support\n- 📝 Detailed and JSON output modes\n\n## Installation\n\n```bash\n# Install dependencies\nbun install\n```\n\n## Usage\n\n### Check System Files\n\n```bash\n# Basic check\nbun run src/cli.ts check\n\n# Verbose output\nbun run src/cli.ts check --verbose\n\n# JSON output\nbun run src/cli.ts check --json\n\n# Check specific path\nbun run src/cli.ts check /path/to/directory\n```\n\n### View Directory Structure\n\n```bash\n# Show directory tree\nbun run src/cli.ts structure\n\n# Limit depth\nbun run src/cli.ts structure --depth 2\n\n# JSON format\nbun run src/cli.ts structure --json\n```\n\n### Quick Scripts\n\n```bash\n# Dev run (shows system status)\nbun run dev\n\n# Check common files\nbun run check\n\n# Detailed check\nbun run check:detailed\n```\n\n## Project Structure\n\n```\n.\n├── src/\n│   ├── cli.ts              # CLI entry point\n│   ├── index.ts            # Main logic\n│   └── commands/\n│       ├── check.ts        # File checking command\n│       └── structure.ts    # Directory structure command\n├── package.json\n├── tsconfig.json\n└── README.md\n```\n\n## Commands\n\n### `check [path]`\n\nCheck system files for existence and details.\n\n**Options:**\n- `--verbose` - Show detailed information\n- `--json` - Output as JSON\n- `--deep` - Deep scan of directories\n\n### `structure [path]`\n\nDisplay directory structure as a tree.\n\n**Options:**\n- `--depth <n>` - Maximum traversal depth\n- `--json` - Output as JSON\n\n## Development\n\n```bash\n# Start development\nbun run dev\n\n# Build project\nbun run build\n\n# Run main\nbun run start\n```\n\n## Requirements\n\n- Bun >= 1.0\n- Node.js >= 18 (optional, for compatibility)\n\n## License\n\nMIT
